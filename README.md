# EVE-Viola

当前版本：**1.1.0**。本次主要增加速度条同款蓝色像素检测、高级逻辑和桌宠 AstrBot 消息推送，完整内容见 [更新记录](CHANGELOG.md)。

EVE-Viola 是一个 Windows 置顶小窗管理器，使用 C++20、Qt 6 Widgets 和轻量 C++ DLL，通过 DWM Thumbnail API 实时显示标题包含 `EVE`（忽略大小写）或`星战前夜`的窗口。

当前版本不依赖 OpenCV；内置区域截取、区域预设、任意颜色像素统计（预设红/白/蓝）、图色规则执行、托盘、快捷切屏和桌宠。点击小窗可激活源窗口。

架构边界、状态同步、配置保护与后台任务生命周期见 [架构说明](docs/architecture.md)。区域冻结截图在后台执行；正常退出会停止接收任务，并在保持界面事件处理的同时等待已启动的截图结束。

“页面分区”页可在当前鼠标所在显示器上拖动绘制水平或垂直辅助线。辅助线始终置顶、不会拦截鼠标，可在列表中选中高亮、重新绘制、编辑粗细/颜色/备注、拖拽排序、删除、清空或撤销；显示状态与线条设置自动保存到 `cache/pagePartition.json`。

## 环境要求

- Windows 10/11 x64
- Visual Studio，安装"使用 C++ 的桌面开发"工作负载
- Qt 6.11.2 `MSVC 2022 64-bit`，默认路径 `D:\Programming\Qt\6.11.2\msvc2022_64`
- Qt 自带工具链位于 `D:\Programming\Qt\Tools`（`CMake_64` 与 `Ninja`）
- 启用桌面窗口管理器（DWM）

## 编译并打包 C++ / Qt 版本

```powershell
.\scripts\build_qt.ps1
```

Windows 下使用 Visual Studio/MSVC 作为编译器。无需另外安装或手动调用系统 CMake：脚本会自动定位 Visual Studio 的 MSVC x64 工具链，并使用 Qt 安装目录下自带的 CMake 与 Ninja。默认 Qt 路径为 `D:\Programming\Qt\6.11.2\msvc2022_64`；若安装在其他位置，可通过 `-QtRoot` 指定。

默认命令会完成 Release 编译和打包，可分发目录位于 `dist-cpp\EVE-Viola`。仅编译、不打包可使用 `-SkipDeploy`；Debug 开发构建可使用：

```powershell
.\scripts\build_qt.ps1 -Configuration Release -SkipDeploy
.\scripts\build_qt.ps1 -Configuration Debug
```

编译后的程序位于 `build\qt-release\cpp\EVE-Viola.exe`（Debug 版本位于 `build\qt-debug\cpp\EVE-Viola.exe`）。

## 构建 C++ DLL

```powershell
.\scripts\build_native.ps1
```

生成文件位于：

```text
build\windows-release\native\eve_viola_native.dll
```

## 单独重新生成可分发目录

```powershell
.\scripts\deploy_qt.ps1
```

正常 Release 构建会自动执行打包；只有需要对已编译程序单独重新打包时才运行此脚本。可分发程序位于 `dist-cpp\EVE-Viola\EVE-Viola.exe`，不要求目标电脑安装 Qt SDK。

重新打包会保留目录中的 `cache` 配置与 `logs`。脚本使用 Windows 平台插件执行启动检查，并移除测试进程对 Qt SDK 环境变量的依赖；`offscreen` 插件仅供开发测试，不包含在分发包中。

## 运行 C++ / Qt 版本

```powershell
.\build\qt-release\cpp\EVE-Viola.exe
```

点击"生成小窗"，随后在新小窗内右键，从"选择完整窗口"菜单选择目标客户端。左键短按小窗会切换并置顶对应 EVE 客户端；首页“小窗管理”与“预设”之间的“软件选项”集中管理全部全局选项。“点击小窗时置于最前”默认开启，开启时还会将被点击的小窗提升到其他小窗上方，关闭后只执行前述客户端跳转，不改变小窗之间的层级。该选项只控制小窗自身，不会改变源进程窗口的置顶逻辑。按住左键约 150 ms 后可拖动小窗，右下角可调整尺寸。首页的"关闭所有小窗"按钮（需确认）会关闭并移除全部小窗。主窗口底部左下角常驻"强制退出"按钮，无论是否勾选"保留到托盘"都会进入退出流程，等待已启动的后台截图结束后关闭所有小窗并退出。小窗列表中的"显示角色名"默认关闭；勾选后会隐藏 DWM 实时预览，将小窗切换为黑色背景，并在中央以橙色显示从 `EVE - 角色名` 提取的角色名。

EVE-Viola 只允许同一个安装目录同时运行一个实例。程序已最小化到托盘时再次启动，不会创建新进程中的主窗口，而会直接恢复并置前已有实例；不同目录中的副本使用各自的实例锁和 `cache`，互不影响。

关闭单个小窗只关闭该实例。启用“保留到托盘”且托盘可用时，关闭主窗口会隐藏到托盘；实际退出时会等待后台截图结束，并清理全部小窗及 DWM Thumbnail。

首页可勾选“随游戏恢复窗口”。启用后，程序会保留勾选预设中暂时缺少源游戏进程的小窗关联；对应 EVE 进程重新启动时，小窗会自动重新启用，并恢复预设中的截取区域、显示状态和窗口位置。

框选区域后，可在“小窗列表”点击“保存预设”。已保存的区域会显示在“区域预设”页，并可重命名、删除或调整该预设的像素统计间隔；之后在任意已选择客户端的小窗中右键，通过“应用区域预设”直接切换区域与统计间隔。

“图色逻辑”页用于新增、编辑和删除规则。每条规则有两个可选的“触发条件”，每个条件把像素颜色（红/白/蓝预设或自定义色值，可单独设置容差）与单边界（`>=20`）或区间（`>15&<60`）合并在一起。一个条件为空时只判断另一个，两个条件都填写时必须同时满足（AND），两个都为空时不触发；触发反馈可选“无/弹窗/播放音频”，播放音频时可挑选音频文件；触发后操作可选“恢复原状态”或“跳转至另一状态”（槽位 1 ↔ 槽位 2 互跳，不再自定义目标）。首页“软件选项”中的“图色逻辑触发时切换到源窗口”默认开启；关闭后仍执行反馈、闪烁和槽位状态变化，但不再自动激活对应源窗口，“自动切换冷却”也会随之禁用。全程序共享两个音频通道：相同音频只播放一次并由所有触发窗口共享完成通知，两个不同音频可同时播放；两个通道均忙时，新的不同音频会被立即忽略且不会排队。共享播放期间某个窗口的条件失效，只取消该窗口的等待，不会误停其他窗口仍需要的音频。播放若未能进入启动状态，会在超时后重建播放器和输出设备并进行有限次数的退避重试，避免首次使用时的瞬时设备故障一直锁死音频通道；音频设备只在真实播放请求到来时初始化，不阻塞普通启动。每次尝试、重试及最终结果都会写入程序目录下的 `logs/eve-viola-YYYY-MM-DD.jsonl`，便于区分无输出设备、媒体格式错误和启动超时。

“软件选项”中的“点击静默”适用于任意位置的鼠标点击（左键、右键、中键和侧键）及所有键盘按键：任一按键按住期间暂停图色逻辑自动切屏，全部松开后继续静默配置的时长，再次点击或按键会重新计时，避免打字时被自动切屏中断。默认时长为 1.5 秒，可调整为 0.1–10 秒。

每个小窗在“小窗列表”里有“启用图色逻辑”开关、“启用槽位”（槽位 1 / 槽位 2）与两个“图色逻辑槽位”。勾选“启用图色逻辑”后执行当前“启用槽位”上的规则，取消勾选则不执行；两槽位各绑定一条规则（或“无”，两槽位不能相同）。对小窗按鼠标中键可在槽位 1 与槽位 2 之间切换（只切换槽位，不会改变开关状态）；长按中键约 1 秒则切换“启用图色逻辑”开关。中键操作不会激活或提升小窗，因此可在小窗被其他小窗部分遮挡时，从仍可见的区域直接切换。当前启用槽位也可由“跳转至另一状态”的规则在完成反馈后自动翻转。小窗按统计间隔轮询，当启用槽位规则的条件在当前画面像素占比上成立时执行其反馈，反馈完成后执行触发后操作。触发采用边沿检测：条件仅在由不满足变为满足时触发一次，持续满足不会重复触发；播放音频期间若条件不再成立会立即打断，等条件下次重新满足时从头触发。

“小窗列表”中的记录可通过编号拖拽调整顺序，顺序会随配置保存。列表左侧显示小窗绑定的源窗口；如果标题含有 ` - `，列表和角色名覆盖层只显示最后一个 ` - ` 之后的内容。来源相同且连续相邻的小窗会自动成组，整组仅在纵向中央显示一格源窗口，并以覆盖组内首尾小窗高度的长条标记范围。小窗组可整体折叠和展开；拖拽或更换来源后会按新的相邻关系实时重组。折叠卡片右侧的“同步到”会保留当前源窗口的小窗，并将其配置复制到目标窗口；目标窗口已有的小窗会先关闭，再生成对应副本。截取区域会在目标窗口范围内尽可能保留，新副本使用新建小窗的位置。每条记录在“小窗当前位置”下方显示“小窗当前尺寸”和“缩放系数”；缩放系数以实际截取区域的原始尺寸为 `100%`，未截取区域时显示 `--%`。

“远征计时”页可选择远征势力与类型，填写出现时间和有效时长，生成并复制到期文本。普通类型自动预填 0 天 23 小时 59 分钟；“三无畏”和“护盾母星”自动预填 2 天 23 小时 59 分钟。

“摸鱼桌宠”页可上传头像图片并裁成圆形头像，再把桌宠显示为屏幕置顶小窗。启用桌宠后，程序下次启动会自动显示。桌宠可用鼠标左键拖动，滚轮调整大小；左键单击打开或收起图色逻辑历史记录气泡，直接显示在头像下方，不另开窗口。保留本次运行最近 10 条触发记录，最新记录在前，超过 10 条自动清除最早记录；显示 `HH:mm:ss` 格式的时间（不含日期）、账号、规则与触发文案，较长时可在气泡内滚动。未填写文案或关闭桌面提示也会记录实际触发；记录不会随提示气泡消失而清空，重启程序后清空。头像缓存为 `cache/desktopPetSource.png`，启用状态、裁剪位置、大小、位置、模式与提示文案保存在 `cache/desktopPet.json`。每条规则可填写最多 120 字的文案，桌宠气泡显示 4.5 秒并附上触发账号名；原本禁用的桌宠会暂时出现，提示结束后收起。

右键菜单提供三种互斥模式，必须选择一种，默认“常驻模式”，选择会在下次启动恢复：

- **常驻模式**：按原设置显示小窗与划线，执行图色逻辑，允许桌宠文字，禁止 AstrBot 推送。
- **摸鱼模式**：隐藏小窗与划线，暂停图色动作，仅保留当前规则条件的后台检测以发送桌宠文字和 AstrBot 提醒；不播放音频、不弹窗、不闪烁、不自动切屏、不跳转槽位，也不增加规则触发次数。
- **勿扰模式**：隐藏小窗与划线，暂停图色逻辑，禁止文字和 AstrBot 提醒，并立即收起已有文字。

文字和 AstrBot 的“允许”仍遵循各自配置开关。切回常驻模式会恢复原先允许显示的小窗与划线；模式不会清空原有配置。设置页也可选择模式，无需上传头像即可使用摸鱼模式推送。右键菜单的“禁用桌宠”下方新增“停止软件”，保存配置并退出整个程序，不会留在托盘。

“高级逻辑”页可启用事件序列白名单，按节点选择图色规则、“保留效果 / 消除效果”和可选的完整源窗口标题。序列从上到下匹配，整串完成时限可设为 0.1–3600 秒；默认关联同一游戏源窗口的多个小窗，也可允许跨源窗口匹配，并选择是否允许中间插入其他事件。最先完成的序列生效，多条同时完成时按白名单列表从上到下优先，匹配事件只消费一次。引用已删除规则的整条序列暂停匹配，可通过编辑更换节点规则。

每条图色规则可设“普通 / 较高 / 最高”优先级，可在“高级逻辑”页或图色规则编辑窗口中修改。最高优先级立即执行，仍参与白名单匹配，且不会被节点的“消除效果”拦截或在匹配完成后重复执行。普通和较高优先级事件仅在仍可能匹配白名单时暂存效果；完整匹配后按节点设置执行或消除，超时或序列中断后恢复原效果，同时释放多个事件时较高优先级先执行。消除涵盖音频、弹窗、自动切屏、边框闪烁、桌宠触发文案与触发后槽位操作；被消除的持续条件不会循环重发，需出现新的条件边沿。关闭小窗、更换源窗口或监控区域、禁用图色逻辑、停止统计时会取消相关序列记录和待判定效果。编辑或关闭白名单会释放原先待判定的效果。

例如设置“本地预警”为最高优先级，再配置“本地预警【保留】→ 加速【消除】”与“刷怪结束【保留】→ 加速【消除】”。本地预警立即提醒，匹配到的后续加速不再告警；没有有效前序事件的孤立加速正常执行图色反馈。可将需要及时提醒的“刷怪结束”同样设为最高优先级。“高级逻辑”默认关闭，旧配置继续按原有图色规则执行。执行或消除判定写入日志的 `advanced_logic_decision` 事件。

区域预设、图色规则、小窗列表等缓存保存在程序根目录的 `cache` 文件夹下，按类别拆分为多个 JSON：`regionPresets.json`、`colorRules.json`、`advancedLogic.json`、`replicas.json`，以及三个预设栏各自的 `preset1.json`、`preset2.json`、`preset3.json`。桌宠设置单独保存在 `desktopPet.json`，上传的头像缓存为 `desktopPetSource.png`；两类设置都使用原子替换写入。主配置遇到损坏的 JSON 时会保留原文件并提示错误。

图色逻辑触发和窗口置顶事件以 UTF-8 JSON Lines 写入程序根目录的 `logs` 文件夹，每天一个文件。触发记录包含小窗编号、槽位、规则编号、红白蓝与自定义颜色像素计数（含容差）及目标窗口标题和 HWND；置顶记录包含自动或手动来源、目标窗口标题和 HWND，以及成功、失败或跳过原因。自动置顶记录通过事件编号关联到对应的图色触发记录。

“小窗列表”默认显示每个小窗当前画面的红色、白色、蓝色像素数量。点击“统计颜色…”可添加、删除颜色，通过选色器或输入 `#RRGGBB` 选择任意颜色，并分别设置容差；颜色设置会随小窗和窗口预设保存。图色规则可独立选择颜色及容差，即使该颜色未在列表中显示也会统计。统计间隔可在 `0 s` 到 `10 s` 之间按 `0.5 s` 调整，默认 `1.0 s`；设为 `0` 即不统计像素。未截取时统计完整客户端画面；截取后只统计当前截取区域。全部小窗由一个全局调度器按间隔错峰统计，最多同时执行两个后台截图批次；同一源窗口不会并发截图，执行时间接近的同源区域会共享一次截图。上一轮尚未结束时会跳过该窗口的过期轮次，不排队补跑。

每行的“显示小窗”开关默认开启。关闭“显示小窗”只会把小窗从屏幕上隐藏，列表记录、截取区域和像素统计仍保留；同时图色逻辑槽位 2 会被锁定并清空为“无”，启用槽位自动重置为槽位 1（槽位 2 选项不可选），“启用图色逻辑”开关自动重新勾选，槽位 1 仍可编辑。是否统计像素由统计间隔是否为 `0` 决定，间隔非 `0` 时开启后台统计，为 `0` 时停止并显示 `--`。只有点击“关闭”才会删除整个小窗。

两个图色逻辑槽位旁各有一个选色按钮（默认槽位 1 为绿色、槽位 2 为蓝色）。小窗外框默认显示 3px 白色边框；勾选“启用图色逻辑”时边框切换为当前启用槽位的颜色（3px），取消勾选时恢复白色。边框闪烁只在条件由不满足变为满足并触发规则的那一刻发生；触发完成后（如“反向等待”期间条件持续满足）边框恢复常亮状态，不再持续闪烁。触发闪烁时只有触发小窗保持闪烁，与它属于同一个“预警区域预设”（即小窗列表“当前区域预设”相同）的其他小窗边框会变为黑色，而不同预设、不同区域的小窗边框照常显示；未关联预设的小窗则按截取区域完全相同来归组。

红色要求 `R` 为最大通道且 `R ≥ 64`、HSV 饱和度不低于 `45%`、色相在 `0°–15°` 或 `345°–360°`；白色为三个通道均不低于 `180`，且最亮与最暗通道之差不超过 `40`。蓝色使用 EVE 界面参考色 `#304F5B`（RGB `48,79,91`），默认每个 RGB 通道允许相差 `16`，包含参考图中的相近蓝灰色。以上范围对应容差框中的“预设范围”，保留已有红白规则的行为；改为数值时分别使用纯红、纯白、EVE 蓝 `#304F5B` 作为目标 RGB。自定义颜色的默认容差为 `32`，可调为 `0`–`255`，每个 RGB 通道与目标色值的绝对差均不超过容差才计入，`0` 表示完全相同。不同颜色独立统计，匹配范围重叠时同一像素可计入多个颜色。判定实现见 `cpp/src/features/replica/pixel_statistics_calculator.cpp`。

桌宠还支持可配置的 AstrBot 主动消息推送：填写服务地址、具有 `im` 权限的 API Key 和接收会话 UMO 后，可将同一条触发文案发送到私聊或群聊。桌面提示与 AstrBot 推送可独立开启，支持测试发送和重复推送冷却；不上传头像也能使用推送。接入步骤与配置说明见 [AstrBot 推送](docs/astrbot_notifications.md)。
